# 風格方向提案：史詩感（待核可）

接續 [01-scope-and-phases.md](01-scope-and-phases.md)。示範檔在 `style-proposal/`。
**核可後才進階段 B**；核可前不改任何遊戲素材、程式色彩或音樂。

## 視覺

目標：低調（low-key）、有重量、只有光源是亮的，像電影裡的古代場景。

| 原則 | 現在 | 史詩感 |
|---|---|---|
| 整體明度 | 沙色高明度、平均亮 | 整體壓暗，亮度集中在人物、光與特效 |
| 色彩 | 大面積淺黃、少數鮮色 | 暗部偏夜靛與暮紫，中間調青銅，高光帝金與象牙；冷暖對比 |
| 光 | 光照範圍已有一圈 | 保留並加強：光源帶暖金光暈，邊緣暈邊（vignette） |
| 特效 | 各色鮮豔 | 保留辨識度，但統一在配色板的聖藍、緋紅、帝金內 |
| UI | 深色底、金邊 | 暮紫底板、帝金邊與標題、象牙文字；字型沿用 Noto Sans TC |
| 解析度 | 640×360 像素風 | 不變 |

配色見 `style-proposal/palette.png`（8 色與用途）。
對比示範見 `style-proposal/compare_*.png`：這是對現有截圖做**調色**，只示範氛圍；實作時要改素材與程式裡的色彩，人物、敵人、地形會重畫成配合新配色。

## 音樂

| 項目 | 現在 | 史詩感 |
|---|---|---|
| 速度 | 約 126–150 BPM | 約 72–96 BPM（Boss、FEVER 可較快） |
| 配器 | 阿洛斯、基薩拉琴、弦樂斷奏、框鼓 | 定音鼓滾奏與太鼓、大提琴低音、弦樂鋪底、銅管主題、合唱、鐘 |
| 動態 | 平均、靠層疊 | 明顯的起伏：弱起 → 主題 → 高潮 → 收尾（示範曲約 16 dB 起伏） |
| 調式 | 各章不同 | 沿用各章調式與「宣教之路」主題，主題改成較慢、較長的樂句 |

示範曲：`epic_sample.ogg`（現在的五旬節見 `before_pentecost.ogg`，可 A/B 對比）。
示範曲是用現有 `make_music.py` 的樂器合成的，沒有外部素材；聖詩旋律仍只用公版曲調。

## 核可後要做的事（階段 B）

1. 把 `style_proposal.py` 的配色收進 token，程式與素材共用同一組色。
2. 改寫 `tools/make_*.py`（人物、敵人、地形、地標、裝飾、特效、營地）使用新配色並加強明暗，**逐章**更新、每章你看過再往下。
3. UI 套件與版面換新（`ui_kit.gd`、`game_ui.gd`、`title.gd`、`camp.gd`、`base.gd`；`ui_kit.gd` 動之前先確認 `wip/0.51-classes-runes` 現況）。
4. 重新作曲：依各章調式與地區配器做新曲，改 BPM 時同步重調同行合擊（`music_bpm`）的判定窗口並多跑一輪玩法測試。

## 已知限制

- `arpg.gd` 這次不動，它的外觀不會跟著換。
- 調色示範沒有重畫人物與地形，最後的質感會比示範更好或不同，示範只用來定方向。
- 風格是主觀的：每一章與每首曲子都要你核可。
