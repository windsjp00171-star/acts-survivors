# 局外裝備層（信物）

使用者選定 03／04 文件裡的「裝備與掉寶」方向（2026-11-18，選項 A）：**裝備跨局保留**。
參考的是 RO 倖存者與 D2 Survivors 的共同循環（失敗不扣東西 → 掉寶累積 → 裝備讓構築變強）。只學結構，名稱、美術、音樂都不沿用。

## 現有系統與這一層的關係

軍裝（`armor`，6 件×3 級）、聖物（`relics`）、膏抹（`anoints`）、果子都只活在一局裡，結束就沒了。
信物是**另一層**：跨局保留、穿在營地，不取代也不改動上面那些。

## 設計

| 項目 | 內容 |
|---|---|
| 部位 | 杖、外衣、草鞋、印章、經卷，共 5 個，每個部位穿一件 |
| 稀有度 | 普通／精良／稀有／傳奇，詞綴數 1／2／3／4，權重 60／28／10／2 |
| 詞綴 | 直接對應永久恩典（`data/meta.json` 的 `bread.upgrades`）：剛強、殷勤、堅忍、更新、收割、長進、奔跑、盾牌。一條詞綴 = 該恩典 +1 級 |
| 上限 | 裝備提供的等級加總後不超過該恩典的 `max`，所以不會比花餅買滿更強；裝備與花餅買的加成是相加的 |
| 掉落 | 精英 10%；Boss（含中途 Boss）必掉，至少精良。數字在 `data/equipment.json` 的 `drop` |
| 行囊 | 最多 24 件；滿了掉的東西折成餅（普通 5、精良 15、稀有 40、傳奇 120） |
| 結算 | 這一局掉的裝備先記在 `run_loot`，結算時才編號放進行囊；該部位還空著就自動穿上 |

## 為什麼這樣接

遊戲裡所有永久加成都經過 `Save.up_value(id)`（`main.gd` 11 個地方用它）。裝備詞綴只要加在 `up_value` 裡，`main.gd` 的戰鬥邏輯完全不用改，也不會新增一套加成管道。

## 存檔

`profile.json` 多一個 `equip`：`{"bag": [...], "worn": {部位: 編號}, "seq": 流水號, "miss": 0}`。
**沒掉過裝備的存檔不會有這個欄位**（不放進 `_defaults`），所以舊存檔、存檔碼與 `tests/unit/save/` 的黃金樣本都不受影響。

## 分階段

1. ✅ 資料與邏輯：`data/equipment.json`、`scripts/equipment.gd`、`Save` 的行囊方法、`up_value` 接線、`tests/unit/equipment/`
2. ✅ 掉落與結算：`main.gd` 的 `_equip_drop`、`_flush_loot`，結算畫面列出掉落
3. ✅ 營地介面：`base.gd` 的「行囊」頁（看、穿上、脫下、賣出），第一次掉到信物後才出現分頁。教學步驟（Rule 15）還沒補，因為專案沒有 `tour.js`
4. 平衡（第一輪完成，見下）：用 storysim 比較有／沒有裝備的勝率與壓力，調掉落率與上限
5. 之後才考慮：卡片槽、裝備自動觸發技能、進化成就任務

## 限制

- 字型是子集（`assets/fonts/NotoSansTC-Game.otf`），裝備名稱只能用字型裡已有的字；改用「草鞋」「印章」「卷」，避開缺字的「涼」「戒」「抄」。新增文字前先查字型，或重跑 `tools/make_font.py`（它的來源字型路徑只適用 Linux）。
- 掉落用的亂數種子取自擊殺數與時間，不動全域亂數，所以固定種子的截圖與測試不會因為掉寶而變。
- 沒做天梯、排行榜、伺服器重播驗證（使用者決定不做）。

## 平衡第一輪（2026-11-18）

`fresh` 存檔（沒有永久恩典）加上 `tools/sim/profiles/fresh_eq.json`（典型：5 件、精良為主）與 `fresh_eqmax.json`（5 件傳奇、詞綴湊滿恩典上限），第 0、1、2 章各 2 局，機器人。

| 章 | 無裝備（用時／等級／驅散） | 典型 | 滿上限 |
|---|---|---|---|
| 0 | 326·365／22·23／3467·3813 | 312·312／23·22／3357·3313 | 321·318／24·23／3600·3365 |
| 1 | 326·320／21·21／3500·3540 | 334·318／22·21／3812·3593 | 311·314／21·21／3462·3508 |
| 2 | 363·370／24·24／4130·4155 | 363·373／25·25／4136·4093 | 363·363／25·25／4120·4102 |

**結論：這組模擬量不出裝備的強度。** 18 局全勝，用時由 Boss 時間軸決定（約 5～6 分鐘），驅散數與等級幾乎沒變；壓力值（導演曲線）在有裝備時較常到上限 7.00，可能是導演在對強的玩家加壓，但單局雜訊大，我不下結論。
所以目前只能確認「滿裝備不會把章節壓垮」，不能確認「掉落率、上限剛好」。要量出差異得用更難的場景（`mid` 存檔打後面的章節、或高信心等級），這輪沒做。
